# Das-rebel Finwipe

## How do I install these formulae?

`brew install das-rebel/finwipe/<formula>`

Or `brew tap das-rebel/finwipe` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "das-rebel/finwipe"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
